---
name: backbone-documents
description: Create and revise retained Backbone HTML Documents when a substantial explanation or authored report needs a durable home.
metadata:
  backbone-tags: all
---

Read `backbone help documents` and `backbone docs documents` for the installed
request schema and limits. Find the intended document and read it before creating
a duplicate or superseding it. Retain its stable document identity when revising.

Validate the request, publish through the supported CLI/API and verify the stored
revision and content. Check rendered HTML when layout matters; a stored-byte
readback alone does not establish visual quality. Use relative links within a
retained artifact only when the reader supports them. Preserve the user's requested
format and destination; saving a Document is distinct from external publication.
